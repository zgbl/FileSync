# FileSync

个人文件同步和版本备份的 Flutter 应用原型。

```sh
flutter pub get
flutter run -d macos
```

打开应用后点击「新建配对」，为至少两台设备分别填写名称并浏览对应的文件夹，然后保存。「添加设备」可继续加入第三台及更多设备；每台设备在同一组内对应一个文件夹。可以新建多组，例如项目资料、照片和文档。保存的配对会在下次打开应用时恢复，也可以在侧栏选中后编辑。

桌面应用可浏览本机、已挂载的移动硬盘和系统选择器可访问的网络共享。浏览器预览（`flutter run -d chrome`）和 iOS 预览可手动填写路径。选中已保存的配对后点「开始同步」：本机能访问到的文件夹（含已挂载的移动硬盘、网络共享）会以修改时间最新的版本为准互相补齐；被覆盖的旧文件先移到该文件夹下的 `.filesync/versions/<时间>/`。删除不会同步，访问不到的文件夹会跳过。远程设备发现和快照恢复仍是演示功能。

macOS 版已关闭 App Sandbox，否则只能只读访问所选文件夹，无法写入。

产品与实现计划见 [设计文档](Design/Design.md)。
